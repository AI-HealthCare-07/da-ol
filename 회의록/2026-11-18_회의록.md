## 4. 결정 사항

- 암호 PDF만 차단. 여러 장 업로드 가능, 파일 1개당 10MB, 합계 30MB
- 한 번 업로드 = 처방 한 건. 병원명·처방일이 다르면 따로 등록
- 확인 화면의 원본 보기는 페이지 이미지로 (PDF 뷰어 안 씀)
- 미확정 파일 삭제 24시간 → 3시간
- 출력 고정(답변 양식 고정, Temperature 0.1~0.2)을 1차로. 담당 이채민, 가이드·챗봇 지시문 적용은 박유정
- 가벼운 일관성 확인: 같은 처방으로 가이드를 5번 만들어 4번 이상 같은 결과면 통과, 1차 시연 전에 AI 파트가 함께 확인
- 저장본 재사용·정식 일관성 평가는 2차
- 마스킹 범위 확대: 주민등록번호·환자번호에 더해 이름·면허번호·연락처까지, LLM에 보내는 글자는 입력 경로와 관계없이 모두 같은 방식
