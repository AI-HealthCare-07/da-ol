## B-1. 처방 등록 (이미지 업로드)
- **상단 헤더:** 뒤로가기 버튼, 페이지 제목(`처방 등록`)
- **문서 종류 선택:** `처방전` / `약봉투` / `퇴원요약지` 선택 탭(또는 버튼)
- **안내 영역:** 촬영·스캔 가이드 안내 (평평한 곳, 그림자 없이, 글자 전체가 보이게 촬영)
- **업로드 액션 영역:**
  - `[카메라로 촬영하기]` 버튼 (모바일 환경 바로 촬영)
  - `[파일 선택하기]` 드래그 앤 드롭 영역 (지원 형식: JPG, PNG, PDF / 파일 1개당 최대 10MB, 여러 장 업로드 합계 최대 30MB)
  - 선택된 파일 목록 및 총 용량 표시 바
- **보안·삭제 안내:** 개인정보(주민번호·이름·면허번호·연락처) 마스킹 처리 및 확정 후 원본 즉시 삭제(미확정 시 3시간 뒤 자동 삭제) 안내 문구
- **하단 보조 버튼:** OCR 없이 직접 입력 시 이동하는 `[직접 입력으로 등록하기]` 버튼

---

## B-2. OCR 분석 로딩 & 실패 안내
### B-2-1. 분석 로딩 화면
- **중앙 영역:** 로딩 스피너 애니메이션 + 안내 문구(`처방전을 읽고 있어요...`)
- **하단 영역:** 취소 버튼

### B-2-2. 분석 실패 화면 (또는 팝업)
- **안내 문구:** `인식에 실패했어요. 사진이 흐리거나 글자를 읽을 수 없습니다. 다시 찍거나 직접 입력해 주세요.`
- **예외 안내:** 문서 종류 불일치 시(`처방전이 아닙니다` 등) 문서 종류 재선택 안내
- **액션 버튼:** `[다시 찍기]` / `[직접 입력]`

---

## B-3. OCR 인식 결과 확인 · 수정
- **원본 대조 뷰어 (PC 좌우 분할 / 모바일 상단 접기·펼치기):**
  - 업로드한 처방전·PDF 원본 이미지(개인정보 마스킹 적용)와 인식된 변환 조건을 나란히 배치
  - 여러 장 업로드 시 이전/다음 페이지 넘김 버튼
- **기본 정보 영역:** 인식된 병원(약국)명, 처방(조제)일 입력/수정 필드
- **인식 약 목록 표(카드):**
  - 항목: 약품명(성분명), 약 형태(먹는 약 / 자가주사 등), 1회 투약량, 투여 주기(매일 / 주 1회 등), 투여 요일(주사약), 회차별 복용 조건(예: 아침·저녁 식후 30분), 복용 시작일, 총 복용 일수, 삭제 버튼
  - **예외 강조:** OCR 신뢰도 `0.8` 미만 항목 및 투여 주기 미인식 항목은 **노란색 배경 강조** + `'확인 필요'` 배지 표시
  - **경고·팝업:** 기존 복용 약과 성분 중복 시 `중복 합치기 팝업` 노출, 병용 금기·주의 약물 감지 시 `병용 주의 경고` 배지 표시
- **목록 추가 버튼:** `[+ 약 추가하기]`
- **2차 기능 자리(레이아웃 영역 확보):** 감량 일정 묶기 안내 영역, 진단명 추가 버튼 (`'진료 준비에 추가'` 및 `'이 페이지 제외'` 버튼은 1차에서 숨김)
- **하단 고정 버튼:** `[확인 및 저장]` (필수 항목 누락 시 비활성화 / 저장 완료 후 첫 처방 등록인 경우 **생활 일과 입력 팝업(`A-5` 컴포넌트)** 노출)

## B-4. 약 수동 등록
- **약품 검색:** 약품명(상품명·성분명) 검색창 (2자 이상 입력 시 자동완성 드롭다운 최대 10개 표시)
- **복용 상세 입력 폼:**
  - `약 형태` (먹는 약 / 자가주사 등)
  - `1회 투약량` (필수, 숫자 및 단위 입력)
  - `투여 주기` (매일 / 주 1회 등) 및 `1일 복용 횟수` (1~4회)
  - `회차별 복용 조건` (필수, 다중 선택 칩: `아침` / `점심` / `저녁` / `취침 전` 및 식전·식후 조건 선택 — 실제 복용 시각은 건강 프로필 일과 기준으로 자동 계산)
  - `복용 시작일` (필수, 캘린더 선택 / 기본값: 오늘)
  - `총 복용 일수` (필수, 1~365일)
  - `병원명 / 메모` (선택 입력)
- **하단 고정 버튼:** `[등록 완료]`

## B-5. AI 복약 · 생활습관 가이드
- **상단 탭 구성:** `복약 가이드` 탭 / `생활습관 가이드` 탭 전환
- **진행 상태 및 검증 배너:**
  - 생성 중 상태 표시: `'가이드 만드는 중 → 내용 확인 중'` (원문 대조 검증 통과 전까지 가이드 본문 미노출)
  - 검증 통과 시 `원문 대조 검증 완료` 배지 표시
- **조건부 팝업 (건강 프로필 미등록 회원 진입 시):**
  - 안내 문구: `건강 프로필을 입력하면 더 정확한 안내를 받을 수 있어요`
  - 버튼: `[건너뛰기]` / `[프로필 입력하기]`
- **가이드 본문 영역:**
  - `복약 가이드 탭`: 현재 복용 중인 약별 핵심 복약 수칙, 주사제 투여 안내, `'확인 필요'` 주의사항 카드
  - `생활습관 가이드 탭`: 식단·운동·수면·금연·절주 실천 행동(3개 이내) 카드
  - 하단 데이터 출처·기준일 및 **의료 면책 문구** 고정 표기
- **예외 상태 화면 (검증 연속 실패 또는 AI 미응답 시):**
  - 공공데이터 기본 의약품 정보와 `'의사·약사에게 확인해 주세요'` 대체 안내 문구 및 `[다시 시도]` 버튼 표시
- **2차 기능 자리(레이아웃 영역 확보):** 단계별 용량 감량 표 영역, 퇴원 후 주의사항 원문 카드
- **하단 이동 버튼:** `[AI 챗봇에게 더 물어보기]`

## B-6. AI 챗봇 상담
- **진입 구조:** 우측 하단 플로팅 챗봇 버튼 클릭 시 열리는 채팅창(또는 전용 상담 화면)
- **상단 헤더:** `AI 복약 상담 챗봇` + 의료 면책 안내 배너
- **대화 영역:**
  - AI 웰컴 메시지 및 현재 복용 중인 **약 이름을 넣은 추천 질문 칩** (예: `[혈압약] 먹고 술 마셔도 돼?`)
  - 사용자 질문 말풍선 / AI 답변 말풍선 (실시간 답변 및 하단 근거 출처 표기)
  - **특수 예외 카드 (우선 노출):**
    - 응급 상황(`약을 실수로 두 번 먹었어요` 등) 입력 시 AI 답변보다 먼저 **빨간 테두리 119 / 109 응급 안내 카드와 전화 연결 버튼** 최상단 표시
    - 처방 변경·중단 질문(`약 끊어도 돼?`, `용량 늘려도 돼?` 등) 입력 시 임의 판단 없이 **의사·약사 상담 안내 카드** 표시
    - 답변 생성 실패 시 `[다시 보내기]` 버튼 표시 (사용량 차감 없음)
- **2차 기능 자리(레이아웃 영역 확보):** 상단 이전 대화 목록 아이콘
- **하단 입력 바:** 질문 입력 텍스트 박스 (**500자 글자 수 카운터 표시**) + `[전송]` 버튼
