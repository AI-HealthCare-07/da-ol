# 화면 설계 (와이어프레임) - 파트 B

> 담당: 이재경
> 범위: 처방 등록(OCR/수동) 4개 화면 + AI 가이드·챗봇 2개 화면
> Figma 링크: (링크 추가 예정)

---

## 1. 처방 등록 (이미지 업로드)
- **상단 헤더:** 뒤로가기 버튼, 페이지 제목(`처방 등록`)
- **안내 영역:** 촬영 가이드 안내 (평평한 곳, 그림자 없이, 글자 전체가 보이게 촬영)
- **업로드 액션 영역:**
  - `[카메라로 촬영하기]` 버튼 (모바일 카메라 실행)
  - `[앨범 / 파일 선택하기]` 영역 (지원 형식: JPG, PNG, PDF / 최대 10MB, 1회 1장)
- **하단 보조 버튼:** OCR 없이 직접 입력 시 이동하는 `[직접 입력으로 등록하기]` 텍스트 버튼

---

## 2. OCR 분석 로딩 & 실패 안내
### 2-1. 분석 로딩 화면
- **중앙 영역:** 로딩 스피너 애니메이션 + 안내 문구(`처방전을 읽고 있어요...`)
- **하단 영역:** 취소 버튼

### 2-2. 분석 실패 화면 (또는 팝업)
- **안내 문구:** `인식에 실패했어요. 다시 촬영하거나 직접 입력해 주세요.`
- **액션 버튼:** `[다시 촬영하기]` / `[수동 입력하기]`

---

## 3. OCR 인식 결과 확인 · 수정
- **상단 요약:** 인식된 병원(약국)명, 처방(조제)일 입력/수정 필드
- **인식 약 목록 표(테이블):**
  - 항목: 약품명, 1회 투약량, 1일 복용 횟수, 총 복용 일수, 복용 시간대, 삭제 아이콘
  - **예외 강조:** OCR 신뢰도 `0.8` 미만 항목은 **노란색 배경 강조** + `확인이 필요해요` 배지 표시
- **목록 추가 버튼:** `[+ 약 추가하기]`
- **하단 고정 버튼:** `[확인 및 저장]` (필수 항목 누락 시 비활성화)

---

## 4. 약 수동 등록
- **약품명 검색:** 입력창 (2자 이상 입력 시 자동완성 드롭다운 최대 10개 표시)
- **복용 상세 입력 폼:**
  - `1회 투약량` (필수, 숫자/단위 입력)
  - `1일 복용 횟수` (필수, 1~4회 선택)
  - `복용 시간대` (필수, 다중 선택 칩: `아침` / `점심` / `저녁` / `취침 전`)
  - `복용 시작일` (필수, 캘린더 선택 / 기본값: 오늘)
  - `총 복용 일수` (필수, 1~365일)
  - `병원명 / 메모` (선택 입력)
- **하단 고정 버튼:** `[등록 완료]`

---

## 5. AI 복약 · 생활습관 가이드
- **조건부 팝업 (건강 프로필 미등록 회원 진입 시):**
  - 안내 문구: `건강 프로필을 입력하면 더 정확한 안내를 받을 수 있어요`
  - 버튼: `[건너뛰기]` / `[프로필 입력하기]`
- **상단 요약 카드:** 현재 복용 중인 약 기준 핵심 복약 수칙 요약
- **상세 가이드 섹션:**
  - 식습관 및 생활습관 주의사항 카드
  - 원문 대조 검증 안내 배지 및 데이터 출처 표기
- **하단 이동 버튼:** `[AI 챗봇에게 더 물어보기]`

---

## 6. AI 챗봇 상담
- **상단 헤더:** `AI 복약 상담 챗봇` + 의료 면책 안내 배너(참고용 안내 문구)
- **대화 영역:**
  - AI 웰컴 메시지 및 추천 질문 칩 (예: `이 약 식전에 먹어도 되나요?`, `함께 피해야 할 음식이 있나요?`)
  - 사용자 질문 말풍선 / AI 답변 말풍선 (답변 하단 근거 출처 표시)
- **하단 입력 바:** 질문 입력 텍스트 박스 + `[전송]` 버튼
