# 화면 설계 (와이어프레임) - 통합본

> - 담당: 김설아
> - 범위: 공통 레이아웃 + 전체 1차 화면(홈·처방 등록·내 약·가이드·챗봇·마이페이지), 2·3차 화면은 자리와 진입점만
> - 기준: 요구사항 정의서 **1차 축소안(11/20)**, 다올 홈 화면 콘셉트(원형 약통·꽃·화단), API 명세서(api-spec.md)
> - 화면 번호: API 명세서의 '화면' 열과 같음 (A-1 ~ F-1)
> - 표시: `(2차)`·`(3차)`가 없으면 1차 구현 범위
> - Figma 링크: [복약 안내 시스템 설계](https://www.figma.com/make/tLODgO62EaTh3oqMgyiMI5/%EB%B3%B5%EC%95%BD-%EC%95%88%EB%82%B4-%EC%8B%9C%EC%8A%A4%ED%85%9C-%EC%84%A4%EA%B3%84?fullscreen=1&t=j36kh49KFUYvaDrt-1&code-node-id=0-6)

## 공통 레이아웃
- **화면 폭:** 360px 모바일 기준으로 그리고, 1920px 데스크톱까지 깨지지 않게 반응형 (REQ-NFR-008)
- **상단 헤더:**
  - 하위 화면: 뒤로가기 버튼 + 페이지 제목
  - 메인 화면(내 약·가이드·마이페이지): 서비스 로고 + 오른쪽 `로그아웃` (REQ-USER-006)
  - 홈: 왼쪽 `상점`(3차) + 가운데 화면 제목 + 오른쪽 `포인트`(3차) · `로그아웃`
  - 로그아웃은 헤더에만 둠 (마이페이지 안에는 두지 않음)
  - 오른쪽 종 아이콘 자리는 비워 둠 (알림 센터, 3차)
- **하단 탭 바 (로그인 후 메인 화면):** `홈` / `내 약` / `[+ 처방 등록]`(가운데 강조 버튼) / `가이드` / `마이페이지`
- **챗봇 플로팅 버튼:** 우측 하단, 하단 탭 바 바로 위 (REQ-CHAT-001)
  - 로그인·추가 정보 입력, 처방 촬영·업로드 화면에서는 숨김
  - 360px 화면에서 하단 버튼과 겹치지 않게 배치
- **글자·버튼 크기:** 본문 16px 이상, 주요 버튼 최소 44×44px. `글자 크게 보기`(본문 20px)는 2차 (REQ-NFR-009)
- **색상:** 약통 몸체 화이트골드, 먹을 차례 웜옐로우, 완료 웜그린. 색만으로 구분하지 않고 체크·아이콘을 같이 씀
- **공통 컴포넌트:**
  - `확인이 필요해요` 배지 + 노란색 배경 (확인 필요 항목)
  - `복용 조건 확인 필요` / `복용 시간 확인 필요` 배지
  - `기본 일과로 계산 중` 배너
  - 빈 상태 화면 (아이콘 + 안내 문구 + 행동 버튼)
  - 확인 팝업 (제목 + 설명 + `[취소]` / `[확인]`)
  - 의료 면책 문구 (가이드·챗봇 공통, 고정 문구)

## A-1. 로그인 / 추가 정보 입력 (REQ-USER-002)

### A-1-1. 로그인
- **상단 영역:** 서비스 로고(알약 캡슐에서 피어난 새싹) + 한 줄 소개
- **액션 버튼:** `[카카오로 시작하기]` 하나만 (이메일·네이버 로그인 없음)
  - 가입한 회원은 바로 홈(A-2), 처음이면 A-1-2로 이동
- **예외 안내:**
  - 카카오 동의 화면에서 취소: `카카오 로그인이 취소되었어요`
  - 인증 실패: `카카오 로그인에 실패했어요. 다시 시도해 주세요`
  - 탈퇴 후 30일 이내 계정: `탈퇴 후 30일 동안은 다시 가입할 수 없어요. ○월 ○일부터 가입할 수 있어요`

### A-1-2. 추가 정보 입력 + 약관 동의
- **입력 폼:** `이름`, `생년월일`(YYYY-MM-DD), `성별` (모두 필수)
- **약관 동의 영역:**
  - `[ ] 전체 동의`
  - `[ ] 서비스 이용약관 (필수)` / `[ ] 개인정보 수집·이용 (필수)` / `[ ] 민감정보(건강정보) 수집·이용 (필수)`, 각 항목 `[보기]`
- **하단 고정 버튼:** `[시작하기]` (필수 항목·동의 누락 시 비활성화)
- **규칙:** 이 화면을 마치기 전에는 다른 화면으로 이동하지 않음 (API는 `PROFILE_REQUIRED`로 막음)
- **완료 후:** 홈(A-2) 빈 상태로 이동
- **파트너 간단 가입 (3차, REQ-NOTI-006):** 파트너 초대 링크로 들어온 사람은 이 화면을 건너뛰고 간단 동의만 받음

## A-2. 홈 - 오늘의 화분 (REQ-MED-005, REQ-MED-016, REQ-MED-017)
- **상단 요약:** 오늘 날짜 + 오늘 복약 현황(예: `3번 중 2번 완료`)
- **요일 미니 약통:** 원 위에 요일 7개를 작은 동그라미로 한 줄 배치
  - 그날 완료율만큼 채워짐
  - 누르면 그날 원으로 바뀌며 살짝 회전. 최근 3일까지 체크·취소 가능, 그 이전은 보기만
- **원형 약통 (하루치):**
  - 칸 수 = 그날 복용 횟수 (1회 원 전체 / 2회 반반 / 3회 아침·점심·저녁 / 4칸까지)
  - 칸 상태 3가지: `먹을 차례`(뚜껑 열림 + 캡슐 아이콘) / `복용 완료`(뚜껑 닫힘 + 체크) / `시간 지남`(연한 경고색)
  - 칸 안: 캡슐 아이콘 + 개수만. 길게 누르거나 펼치면 약 이름, 1회 용량, 복용 조건(예: `식후 30분`)
  - 칸을 누르면 뚜껑이 닫히는 짧은 애니메이션, 다시 누르면 체크 취소
  - `복용 시간 확인 필요` 약: 칸 대신 안내 문구 + `[끼니 고르기]` (REQ-MED-009)
- **원 가운데 화분:**
  - 새싹 + 다음 복용 시간(예: `점심까지 2시간`)
  - 그날 칸을 모두 닫는 순간 새싹이 꽃으로 피는 애니메이션 (기본 꽃 1종)
  - 놓친 회차가 있어도 시들거나 죽는 연출은 쓰지 않음 (REQ-NFR-018)
  - 꽃을 화단으로 옮기는 연출·`+5P`는 각각 2차·3차
- **오늘 체크리스트:** 약통 아래에 회차별 카드 목록 (시각 + 약 이름 + 1회 용량·복용 조건 + 체크 버튼, 다시 누르면 취소). 약통 칸과 같은 상태를 공유
  - `복용 시간 확인 필요` 약은 시각 대신 `?` + `[아침]` / `[점심]` / `[저녁]` 선택
- **필요할 때 복용 영역:** 필요시 약은 약통과 따로 목록으로 표시, 완료 개수에서 제외 (REQ-MED-008)
- **기본 일과 배너:** `기본 일과(기상 07:00 · 식사 08:00·12:30·18:30 · 취침 23:00)로 계산 중` 표시만. 내 일과 입력으로 가는 링크는 2차 (REQ-USER-013)
- **화단 이동 (2차):** 화면을 오른쪽으로 밀거나 위쪽 `‹ 내 화단` → A-3 (페이지 점 2개로 표시)
- **가이드 안내:** 처방을 저장하고 홈으로 돌아오면 맨 위에 `약통에 새 약이 들어갔어요 · 가이드를 만들고 있어요` 안내 → 누르면 D-2
- **빈 상태:** `처방전을 찍어 약을 등록해 보세요` + `[처방 등록하기]` → B-1

## A-3. 내 화단 (2차, REQ-MED-019)
- **달력형 화단:** 이번 달만 7열 × 5~6행 달력 모양. 그날 꽃이 핀 날은 꽃, 놓친 날은 빈 흙
- **연속 기록:** `연속 기록 N일째` (REQ-MED-018)
- **오른쪽 위:** `통계` 버튼 → A-4
- **화단 앨범 (3차, REQ-MED-020):** 지난달 화단을 읽기 전용으로 넘겨 보기
- **꾸미기 공간 (3차):** 여러 칸을 차지하는 상품(소나무 분재 등)은 달력 바깥 테두리·옆 정원에 배치
- **쉼표 (3차, REQ-MED-024):** 자리만

## A-4. 복약 통계 (2차, REQ-MED-021)
- **탭:** `일주일` / `한 달` / `1년`
  - 일주일: 요일별 복용률 막대 7개 + 시간대별(아침·점심·저녁) 복용률
  - 한 달: 복용률(%), 피운 꽃 수, 최장 연속 기록 숫자 요약
  - 1년: 날짜별 꽃 피운 여부 잔디 그래프 + 월별 복용률
- **계산식:** 순응도 = 복용 완료 횟수 ÷ 복용 예정 횟수 × 100

## A-5. 꽃 상점 (3차, REQ-MED-023)
- 꽃 씨앗 카드(이름·그림·가격) + `[구매]` → 구매 확인 팝업, 계절 한정 꽃·연속 기록 특별 꽃·소나무 분재
- **다음에 키울 꽃:** 산 꽃 중 하나를 골라 두면 다음 날 그 꽃이 핌 (기본 데이지)
- 현금성 보상(상품권 교환, 포인트 결제)은 넣지 않음

## A-6. 포인트 내역 (3차, REQ-MED-022)
- 보유 포인트 + 적립(하루 완료 5P, 연속 달성 보너스)·사용 내역 목록

## B-1. 처방 등록 (REQ-OCR-001, REQ-OCR-002, REQ-MED-001)

### B-1-1. 업로드
- **문서 종류 선택:** `처방전`(약 받기 전) / `약봉투`(이미 받은 약)
- **안내 영역:** 촬영 가이드 (평평한 곳, 그림자 없이, 글자 전체가 보이게)
- **업로드 액션 영역:**
  - `[카메라로 촬영하기]` (모바일 바로 촬영)
  - `[파일 선택하기]` 드래그 앤 드롭 영역 (JPG·PNG·PDF / 파일 1개 10MB, 합계 30MB, 여러 장 가능)
  - 선택된 파일 목록 + 총 용량 표시 바, 파일마다 `↑` `↓`(페이지 순서 바꾸기) · `×`(삭제)
- **보안·삭제 안내:** 개인정보(주민번호·이름·면허번호·연락처) 가림 처리, 확정 후 원본 즉시 삭제(미확정 시 3시간 뒤 자동 삭제)
- **하단 보조 버튼:** `[직접 입력하기]` → B-1-3

### B-1-2. 읽는 중 / 실패
- **읽는 중:** 로딩 애니메이션 + `처방전을 읽고 있어요...` (2초마다 상태 확인) + `[취소]`
- **실패:**
  - `글자를 읽지 못했어요. 사진이 흐리거나 잘렸을 수 있어요. 다시 찍거나 직접 입력해 주세요`
  - 문서 종류가 다르면(`처방전이 아닌 것 같아요`) 문서 종류 다시 고르기
  - 3시간이 지나 원본이 삭제되면 `시간이 지나 사진이 삭제됐어요. 다시 올려 주세요`
  - 버튼: `[다시 찍기]` / `[직접 입력하기]`
- **완료:** B-2로 이동

### B-1-3. 직접 입력 (REQ-MED-001, 1차 축소 범위)
- **약 검색:** 상품명·성분명 검색창, 2자 이상 입력 시 자동완성 최대 10개
- **약마다 입력:**
  - `1회 용량` (필수, 숫자 + 단위: 정·캡슐·포·mg·mL)
  - `1일 복용 횟수` (필수, 1~4회)
  - `회차별 복용 조건` (필수, 선택 칩: `식전 n분` / `식후 n분` / `취침 전` / `필요시`)
  - `복용 시작일` (필수, 기본값 오늘)
  - `총 복용 일수` (필수, 1~365일)
- **목록 추가:** `[+ 약 추가하기]`로 여러 약을 한 처방으로 등록
- **하단 고정 버튼:** `[등록 완료]` (필수 항목 누락 시 비활성화) → 홈(A-2) + 가이드 생성 안내
- **복용 시각:** 회원이 고르지 않고 기본 일과로 자동 계산
- **2차:** 식간·공복·n시간 간격 조건, 문장으로 입력한 복용법 해석, 병원명·메모

## B-2. 인식 결과 확인 · 수정 (REQ-OCR-004, REQ-OCR-005, REQ-MED-008, REQ-MED-009)
- **원본 대조 뷰어 (PC 좌우 분할 / 모바일 상단 접기·펼치기):**
  - 업로드한 원본(가림 처리 적용, PDF는 페이지 이미지)과 인식 결과를 나란히 배치
  - 여러 장이면 이전/다음 페이지 버튼
- **기본 정보:** 병원(약국)명, 처방(조제)일 수정 필드
- **인식 약 목록 (카드):**
  - 항목: 약품명, 1회 용량, 1일 복용 횟수, 총 복용 일수, 복용 시작일(기본값 처방일, 없으면 오늘), 회차별 복용 조건, 삭제 버튼
  - 처방전 원문 문구 옆에 변환된 복용 조건을 나란히 표시
  - 인식 신뢰도 0.8 미만 항목: 노란색 배경 + `확인이 필요해요`
  - `복용 조건 확인 필요`: 목록에서 직접 고르기 (`식전 n분` / `식후 n분` / `취침 전` / `필요시`)
  - `복용 시간 확인 필요`(1일 1·2회인데 끼니가 안 적힘): 아침·점심·저녁 중 고르기
- **약품 매칭:**
  - 매칭 후보가 여러 개면 상위 3개 중 선택, 고르지 않으면 다른 약 정보를 대신 연결하지 않음
  - 매칭 실패: `등록되지 않은 약품` + 약 검색(B-1-3과 같은 검색창)으로 직접 고르기, 끝내 없으면 `이 약은 안내 정보가 없습니다`
- **예외:**
  - 같은 줄이 두 번 읽힘: `같은 약이 두 번 읽혔어요. 하나로 합칠까요?` (자동으로 합치지 않음)
  - 용량만 다른 같은 약: 합치지 않고 `같은 약이 용량만 다르게 여러 줄 있어요. 처방전을 확인해 주세요`
  - 먹는 약이 아닌 줄: 회색 + `먹는 약만 등록할 수 있어요`, `[먹는 약이에요]`로 되돌리기
- **목록 추가 버튼:** `[+ 약 추가하기]`
- **하단 고정 버튼:** `[확인 및 저장]` (필수 항목 누락 시 비활성화) → 원본 삭제 → 홈(A-2)에 약통 칸 생성 + `가이드를 만들고 있어요` 안내
- **2차:** 병용 주의 경고(DUR), 투여 주기, 첫 처방 뒤 생활 일과 입력 팝업

## C-1. 내 약 목록 / 처방 상세 (REQ-MED-002)
- **탭:** `복용 중` / `복용 종료`
- **처방 묶음 헤더:** 병원명 · 처방일 + `[가이드 보기]` → D-2 / `⋮` 메뉴(수정·삭제, 2차, REQ-MED-004)
- **처방 상세 (헤더를 펼치면):** 약별 회차 시각(기본 일과로 계산), `복용 시간 확인 필요` 표시
- **약 카드:**
  - 상품명(성분명) (예: `다이아벡스(메트포르민)`)
  - 복용법 (예: `1일 3회 식후 30분`)
  - 남은 일수
  - 병용 주의 표시 (2차, REQ-MED-007)
- **카드 클릭:** C-2 약 상세 정보
- **빈 상태:** `등록한 약이 없어요` + `[처방 등록하기]` → B-1

## C-2. 약 상세 정보 (REQ-MED-002)
- **상단 영역:** 약 이미지(공공데이터에 있을 때) + 상품명(성분명) + 제조사
- **내 복용 정보 카드:** 회차별 복용 조건, 계산된 복용 시각, 남은 일수 / `[복용 시각 수정]` (2차, REQ-MED-010)
- **약 정보 섹션 (접기/펼치기):** 효능, 용법·용량, 주의사항, 주요 부작용, 보관법
- **하단 영역:** 출처 + 기준일 (예: `출처: 식약처 공공데이터 · 2026-11-01 기준`)
- **예외:** 공공데이터에 없는 약은 `이 약은 안내 정보가 없습니다` + 내 복용 정보 카드만 표시 (REQ-OCR-005)

## D-2. 복약 · 생활습관 가이드 (REQ-GUIDE-001, 002, 006, 007, REQ-VERI-001, 004)
- **상단 탭:** `복약 가이드` / `생활습관 가이드`
- **헤더 오른쪽:** `듣기` (3차, REQ-EXT-002)
- **진행 상태:** `가이드 만드는 중 → 내용 확인 중` (검증이 끝나기 전에는 본문을 보여 주지 않음)
  - 전체 `검증 완료` 배지는 넣지 않음. 회원이 의사가 확인한 내용으로 오해할 수 있음
  - `출처 확인됨` 표시는 2차 (REQ-VERI-006)
- **조건부 팝업 (건강 프로필 미입력 회원):** `건강 프로필을 입력하면 더 정확한 안내를 받을 수 있어요` + `[건너뛰기]` / `[프로필 입력하기]` → E-2
- **복약 가이드 탭:** 약마다 4칸
  - `먹는 법` / `주의할 점` / `부작용·대처` / `병원에 가야 할 증상`
  - 용량·횟수·일수·복용 시각은 확정 처방 값 그대로 표시
  - 검증에 걸린 항목은 공공데이터 기본 약 정보로 대체하고 `확인이 필요해요` 표시 (REQ-VERI-005 1차 범위)
- **생활습관 가이드 탭:** 식단·운동·수면·금연·절주 실천 행동 카드 (3개 이내)
- **하단 고정:** 근거 문서 출처·기준일 + 의료 면책 문구
- **실패 화면 (30초 안에 끝나지 않거나 AI 응답 실패):**
  - 공공데이터 기본 약 정보 + `가이드를 만들지 못했어요. 다시 시도해 주세요` + `[다시 시도]`
  - 자동 재시도는 2차
- **하단 이동 버튼:** `[챗봇에게 더 물어보기]` → F-1
- **2차:** 가이드 다시 만들기(REQ-GUIDE-005), 만족도 평가(REQ-GUIDE-008)

## E-1. 내 정보 (마이페이지 > 내 정보 탭)
- **마이페이지 탭:** `내 정보` / `건강 프로필` / `알림 설정`(2차, 카카오톡 알림) / `화면 설정`(2차)
- **내 정보 (1차):** 프로필 이미지, 닉네임, `카카오 계정으로 로그인 중` (로그아웃은 상단 헤더)
- **2차:** 이름·생년월일·성별 등 전체 항목 표시(REQ-USER-008), 프로필 이미지·닉네임 수정(REQ-USER-009), 회원탈퇴(REQ-USER-011, `탈퇴하면 30일 후 모든 기록이 삭제되고, 그동안 다시 가입할 수 없어요`)

## E-2. 건강 프로필 (마이페이지 > 건강 프로필 탭) (REQ-USER-010)
- **기본 정보:** 키(cm), 몸무게(kg)
- **기저질환:** 다중 선택 칩 (`고혈압` / `당뇨` / `이상지질혈증` / `심장질환` / `신장질환` / `간질환` / `없음` / `기타 직접입력`)
- **기타 항목:** 약물·식품 알레르기(직접입력), 임신·수유 여부(여성만 표시), 흡연 여부, 음주 빈도(주 n회), 운동 빈도(주 n회)
- **하단 고정 버튼:** `[저장]`
- **생활 일과 섹션 (2차, REQ-USER-013):** 기상·아침·점심·저녁·취침 시간, 끼니마다 `먹지 않음`, 평일/주말 토글. 1차는 기본 일과 값을 읽기 전용으로 보여 줌

## F-1. AI 복약 상담 챗봇 (REQ-CHAT-001, 002, 004, 005)
- **진입:** 챗봇 플로팅 버튼, D-2 `[챗봇에게 더 물어보기]`. 열 때마다 새 대화
- **상단 헤더:** `AI 복약 상담` + 의료 면책 안내 배너
- **대화 영역:**
  - 웰컴 메시지 + 복용 중인 약 이름을 넣은 추천 질문 칩 3개 (예: `[혈압약] 먹고 술 마셔도 돼?`)
  - 질문 말풍선 / 답변 말풍선 (글자가 실시간으로 이어서 나옴) + 답변 아래 근거 출처
- **특수 카드 (AI 답변보다 먼저):**
  - 응급 상황(예: `약을 한꺼번에 많이 먹었어요`): 빨간 테두리 119 / 109 안내 카드 + 전화 연결 버튼
  - 진단·처방 변경 질문(예: `약 끊어도 돼?`, `용량 늘려도 돼?`): 의사·약사 상담 안내 카드 + `진료 준비에 추가`(2차, REQ-MED-015)
  - 답변 실패: `답변을 불러오지 못했어요` + `[다시 보내기]` (사용 횟수 차감 없음)
- **하단 입력 바:** 입력창(500자 글자 수 표시) + `[전송]`
- **2차:** 이전 대화 목록(REQ-CHAT-003), 사용량 제한 안내(REQ-CHAT-006)

## 화면 연결
- 로그인 → (처음이면) 추가 정보 입력 → 홈
- 하단 탭 `[+ 처방 등록]`, 홈·내 약·가이드 빈 상태 버튼 → B-1
- B-1 업로드 → 읽는 중 → B-2 `[확인 및 저장]` → 홈(약통에 반영 + 가이드 생성 안내) → 안내를 누르면 D-2
- B-1 실패·`[직접 입력하기]` → B-1-3 `[등록 완료]` → 홈(약통에 반영 + 가이드 생성 안내)
- C-1 `[가이드 보기]`, 하단 탭 `가이드` → D-1 → D-2
- D-2 건강 프로필 미입력 팝업 `[프로필 입력하기]` → E-2
- D-2 `[챗봇에게 더 물어보기]`, 플로팅 버튼 → F-1
- 홈 `내 화단`(2차) → A-3 → `통계` → A-4

## 이전 문서(파트 A·B)에서 바뀐 점
- 로그인: 이메일 회원가입·로그인 삭제, 카카오 로그인 + 추가 정보 입력으로 변경 (11/19 결정)
- 홈: 시각별 카드 목록 → 원형 약통 + 가운데 화분(꽃 피우기)으로 변경, 화단·통계·상점·포인트 화면 추가 (2·3차)
- 범위 축소(11/19): 퇴원요약지, 주사약, 투여 주기·요일, 감량 일정, 진단명 관련 영역 삭제
- 1차 축소안(11/20): 생활 일과 입력·DUR·검증 재생성 2차, 직접 입력(MED-001)은 1차 축소 범위로 유지
- 가이드(유정님 리뷰 반영): 전체 `검증 완료` 배지 삭제, 복약 가이드 약마다 4칸, 응급 예시 문구를 `약을 한꺼번에 많이 먹었어요`로 변경
- 화면 번호: A-1 ~ A-6 / B-1 ~ B-6 → API 명세서와 같은 A~F 그룹 번호로 변경
- 여러 장 업로드: 1차 확정 (파일 1개 10MB, 합계 30MB) (11/18 회의, 재경님 리뷰 반영)
- 처방 저장 후 이동: 가이드 화면 → 홈으로 변경 (등록 결과가 약통에 바로 보이도록, 11/20 결정)
- 로그아웃: 상단 헤더에만 둠 (11/20 결정)
