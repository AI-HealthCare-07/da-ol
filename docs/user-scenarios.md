# 다올 사용자 시나리오

2026-11-19 · 김설아 (11/17 초안 수정)

요구사항 정의서 v10(77개) 기준으로, 대표 타겟에 맞춘 가상 회원 2명이 다올을 쓰는 흐름을 정리했습니다. 시나리오 1은 데모데이 1차 시연 흐름이고, 시나리오 2는 2차 기능으로 차별점을 넓히는 흐름입니다.

- **대표 타겟**: 고혈압·당뇨·이상지질혈증 등 만성질환으로 여러 먹는 약을 오래 복용하는 중장년·고령 환자. 시스템은 먹는 약을 복용하는 누구나 쓸 수 있게 설계합니다.
- **범위**: 먹는 약만 다룹니다. 주사·기타 약, 퇴원요약지, 감량 일정, 냉장 보관 안내는 제외했습니다. (11/19)
- **쓰는 곳**: 와이어프레임(화면 순서), API 명세서(화면별 필요한 요청), 배포 전 검수 시나리오(REQ-NFR-011)의 출발점
- **표 읽는 법**: 단계마다 회원 행동, 시스템 동작, 보이는 화면, 관련 요구사항 ID를 적었어요. '확인 포인트'는 그대로 테스트 케이스로 쓸 수 있어요.
- **구현 단계**: 요구사항 옆 (2차)·(3차) 표시가 없으면 1차예요.
- **약을 등록하는 사람**: 약은 복용하는 사람 본인 계정에 등록해요. 보호자는 가입과 등록을 옆에서 돕는 역할이에요. (가족 프로필은 이번 범위에서 제외)

※ 약품명·처방 내용은 설명을 위한 가상 예시이며, 실제 의학적 판단이 아닙니다.

**예외 흐름 (1차)**

1. 사진이 흐려서 글자를 못 읽으면 '다시 찍기 / 직접 입력' 버튼을 보여주고, 직접 입력은 약 이름 검색(상품명·성분명)으로 등록해요. (OCR-002, MED-001)
2. 처방전에 주사나 연고 줄이 섞여 있으면 회색으로 '먹는 약만 등록할 수 있어요'를 보여주고 저장하지 않아요. 잘못 분류됐으면 '먹는 약이에요'로 되돌려요. (OCR-003, OCR-004)
3. 가이드가 검증에 계속 실패하거나 AI가 응답하지 않으면, 문제 부분을 공공데이터 기본 정보와 '의사·약사에게 확인해 주세요'로 대신 보여주고 '다시 시도' 버튼을 두어요. (VERI-005, GUIDE-007)
4. 저녁 칸을 체크하지 못하고 하루가 끝나면 꽃이 피지 않고 그날은 빈 흙으로 남아요. 시들거나 죽는 연출은 쓰지 않아요. (MED-017, NFR-018)
5. 챗봇 답변이 실패하면 '다시 보내기' 버튼을 보여주고 사용량에서 차감하지 않아요. (CHAT-001)

**확인 포인트**

- [ ] '확인'을 누르기 전에는 처방이 저장되지 않고 시간표도 계산되지 않음
- [ ] 검증을 통과하기 전의 가이드는 화면에 나오지 않음
- [ ] 가이드에 처방에 없는 약 0건, 복용 중단·용량 변경 권유 0건, 면책 문구 누락 0건
- [ ] 처방 확정 후 원본 사진이 삭제됨
- [ ] 약통 칸 수가 그날 복용 회차 수(30분 이내 묶음은 한 칸)와 같음
- [ ] 하루 칸을 모두 닫았을 때만 꽃이 피고, 체크를 취소하면 꽃과 포인트도 취소됨
- [ ] 응급 안내가 AI 답변보다 먼저 나오고, 처방 변경 질문에는 답하지 않음

## 시나리오 2. 약이 늘어난 직장인의 맞춤 시간표와 화단 (2차 차별점)

**가상 회원 B** · 54세 남성, 당뇨·이상지질혈증. 회사에 다니며 평일에는 07:00에 일어나 아침을 거르고, 12:30 점심, 19:30 저녁, 00:30에 자요. 주말에는 09:00에 일어나 세 끼를 다 먹어요. 원래 이상지질혈증약(1일 1회 취침 전, 30일)을 먹고 있었는데, 이번에 당뇨약(1일 3회 식후 30분, 30일)이 새로 추가됐어요. 가입은 마쳤어요.

**예외 흐름**

1. 일과를 입력하지 않았다면 기본값(기상 07:00, 식사 08:00 / 12:30 / 18:30, 취침 23:00)으로 계산하고 '기본값 사용 중'을 표시해요. (USER-013)
2. 회원이 약사에게 물어보지 않고 당뇨약 시각을 직접 바꾸면, 식후 약을 식사 전으로 옮기는 경우 경고를 띄우고, 저장은 허용하되 진료 준비 질문에 남겨요. (MED-010, 2차)
3. 점심이 아침보다 이르게 입력하면 저장하지 않고 다시 입력하라고 안내해요. (USER-013)
4. 지난 날짜 체크를 고쳐(최근 3일까지) 하루가 완료되면 꽃은 심지만 포인트는 주지 않아요. (MED-017)

**확인 포인트**

- [ ] 일과로 처방 조건을 지킬 수 없을 때 시스템이 임의로 시간을 정하지 않음
- [ ] 첫날 등록 전에 지나간 회차가 '미복용'으로 기록되지 않음
- [ ] 자정 넘어 먹은 취침 전 약이 전날 기록으로 남음
- [ ] 일과를 바꿔도 오늘 이미 체크한 기록은 바뀌지 않음
- [ ] 해결된 질문이 지워지지 않고 '해결됨'으로 남음
- [ ] 놓친 날이 생기면 연속 기록은 0일부터 다시 세지만, 이미 심은 꽃은 그대로 남음
- [ ] 같은 일과·처방이면 시간표가 항상 같게 계산됨 (NFR-015)
