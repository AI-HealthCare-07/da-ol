# 다올 사용자 시나리오

2026-11-17 · 김설아

요구사항 정의서 최종본(79개) 기준으로, 가상 회원 3명이 다올을 쓰는 흐름을 정리했습니다. 시나리오 1과 1-B(당뇨 주사)는 데모데이 1차 시연 흐름이고, 2·3은 2차 기능으로 차별점을 넓히는 흐름입니다.

- **쓰는 곳**: 와이어프레임(화면 순서), API 명세서(화면별 필요한 요청), 배포 전 검수 시나리오(REQ-NFR-011)의 출발점
- **표 읽는 법**: 단계마다 회원 행동, 시스템 동작, 보이는 화면, 관련 요구사항 ID를 적었어요. '확인 포인트'는 그대로 테스트 케이스로 쓸 수 있어요.
- **구현 단계**: 요구사항 옆 (2차)·(3차) 표시가 없으면 1차예요.
- **약을 등록하는 사람**: 약은 복용하는 사람 본인 계정에 등록해요. 보호자는 가입과 등록을 옆에서 돕는 역할이에요. (가족 프로필은 이번 범위에서 제외)

※ 약품명·처방 내용은 설명을 위한 가상 예시이며, 실제 의학적 판단이 아닙니다.

## 시나리오 1. 처방전 한 장으로 시작하는 복약 관리 (1차 시연 흐름)

- [ ] 처방 확정 후 원본 사진이 삭제됨
- [ ] 응급 안내가 AI 답변보다 먼저 나오고, 처방 변경 질문에는 답하지 않음

## 시나리오 1-B. 주 1회 당뇨 주사가 추가된 경우 (1차 차별점)

**가상 회원 A, 3개월 뒤** · 내과에서 당뇨 진단을 받고, 기존 약에 더해 집에서 스스로 맞는 주 1회 당뇨 주사를 처방받았어요. 매주 토요일 아침에 맞기로 했어요.

| 단계 | 회원 행동 | 시스템 동작 | 화면 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 새 처방전을 찍어 올림 | 투여 경로 '주사', 투여 주기 '주 1회', 용량을 처방전 단위 그대로 추출 | 처방 등록, 로딩 | OCR-001~003 |
| 2 | 확인 화면에서 약 형태 '자가주사', 주 1회를 확인하고 투여 요일(토요일)과 시각(09:00)을 고름 | 주사약은 식사 조건 없이 요일과 시각만 저장. 첫 투여일을 기준으로 다음 투여일 계산 | 인식 결과 확인 | OCR-004, MED-012 |
| 3 | '확인'을 누름 | 복용 중인 혈압약·고지혈증약과 병용 주의 확인. 냉장 보관 약이면 '냉장 보관' 표시와, 처방전 등록이라 '받기 전에 약국에서 확인해 주세요' 안내 | 인식 결과 확인 | MED-007, MED-014 (2차) |
| 4 | 갱신된 복약 가이드를 읽음 | 주사약은 '복용' 대신 '투여'로 쓰고 식사 조건을 붙이지 않음. 검증에서 용량·주기를 처방과 대조 | 가이드 | GUIDE-001, VERI-001 |
| 5 | '내 약'에서 주사약 카드를 봄 | 상품명(성분명)과 다음 투여일(예: 11/21 토) 표시 | 내 약 | MED-002, MED-012 |
| 6 | 평일과 토요일에 홈 화면을 엶 | 평일에는 먹는 약만, 토요일에는 09:00 주사가 함께 표시됨 | 홈(오늘의 복약) | MED-005, MED-012 |
| 7 | 챗봇에 '혈당이 높은데 이번 주는 주사 용량 늘려도 돼?' 입력 | 용량 변경 요청으로 판단해 답하지 않고 의사·약사 상담 안내 | 챗봇 창 | CHAT-005, VERI-004 |

**예외 흐름**

1. 처방전에서 투여 주기를 못 읽으면 '매일'로 채우지 않고 '투여 주기 확인 필요'를 표시해 회원이 목록에서 고르게 해요. (MED-012)
2. 인슐린처럼 하루 여러 번, 식사 직전에 맞는 주사는 처방전에 적힌 식사 조건을 적용해 시간표를 계산해요. (MED-008, MED-012)
3. 용량이 범위로 적혀 있으면(예: 혈당에 따라 4~8단위) 범위를 그대로 보여주고, 앱이 그중 하나를 고르거나 계산하지 않아요. (MED-012, VERI-001)

**확인 포인트**

- [ ] 주사약이 투여일에만 '오늘의 복약'에 나오고, 다음 투여일이 정확함
- [ ] 주기를 못 읽었을 때 '매일'로 자동 입력되지 않음
- [ ] 가이드에 주사약을 '복용'으로 쓰거나 식사 조건을 붙이지 않음
- [ ] 앱이 용량을 계산·추천하지 않고, 용량 변경 질문에 답하지 않음

## 시나리오 2. 퇴원 후 용량을 줄여 가는 약 관리 (차별점)

**가상 회원 B** · 72세 남성. 폐렴으로 입원했다가 퇴원하면서 퇴원요약지(3장)와 퇴원약을 받았어요. 퇴원약에는 5일마다 용량을 줄여 가는 스테로이드와 위장약이 있어요. 평소 06:00 기상, 07:00 / 12:00 / 18:00 식사, 21:30 취침. 가입과 일과 입력은 마쳤어요.

| 단계 | 회원 행동 | 시스템 동작 | 화면 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 문서 종류 '퇴원요약지'를 고르고 3장을 올린 뒤 페이지 순서를 확인 | 최대 5장 업로드, 순서 변경 가능 | 처방 등록 | OCR-001, OCR-006 (2차) |
| 2 | — | 진단명, 퇴원 약물, 퇴원 후 주의사항을 추출. '퇴원 약물' 섹션의 약만 처방 후보로 올리고, 입원 중 맞은 주사는 빼기 | 로딩 | OCR-006 (2차) |
| 3 | 확인 화면에서 스테로이드가 용량만 다르게 4줄 있는 것을 봄 | '용량을 단계적으로 바꾸는 처방인가요?'를 묻고, 회원이 순서를 확인하면 하나의 감량 일정(1~5일째 4정 → 6~10일째 3정 → 11~15일째 2정 → 16~20일째 1정)으로 묶기 | 인식 결과 확인 | OCR-004, MED-013 (2차) |
| 4 | 같은 화면에서 진단명 '폐렴'을 확인하고 '건강 프로필에 추가'를 누름 | 진단명을 문서 표현 그대로, 출처(병원명·날짜)와 함께 현병력으로 저장. 퇴원 후 주의사항('2주간 무리한 운동 금지')도 원문 그대로 저장 | 인식 결과 확인 | OCR-007, USER-010 (2차) |
| 5 | '확인'을 누름 | 퇴원요약지는 이미 받은 약이라 수령 전 안내를 띄우지 않음. 감량 일정으로 묶인 줄끼리는 같은 성분 중복 경고를 띄우지 않음 | — | MED-014 (2차), MED-007 |
| 6 | — | 일과로 시간표 계산: 스테로이드 07:30, 위장약 07:30 / 18:30. 같은 식후 조건이라 07:30에 한 묶음으로 표시 | — | MED-008, MED-009 |
| 7 | 복약 가이드를 읽음 | 단계별 용량을 표로 보여주고, 검증에서 단계마다 용량을 대조. 생활습관 가이드 맨 위에 퇴원 후 주의사항 원문을 먼저 보여주고, 운동 권유는 그에 맞춰 조절 | 가이드 | GUIDE-001, GUIDE-002, VERI-001, VERI-003 |
| 8 | '복약 기록' 캘린더를 열어 앞으로의 용량을 봄 | 날짜별 용량(4정 → 3정 → …) 표시 | 복약 기록 | MED-006 (2차), MED-013 |
| 9 | 6일째 아침 홈 화면을 엶 | '오늘의 복약'에 '오늘부터 3정입니다' 표시 (알림을 구현하면 알림에도 표시) | 홈(오늘의 복약) | MED-005, MED-013, NOTI-002 (3차) |
| 10 | 3주 뒤 폐렴이 다 나아 건강 프로필에서 '폐렴'을 과거력으로 옮김 | 이후 가이드·챗봇은 현병력만 사용. 퇴원 처방이 끝나서 운동 제한 주의사항도 가이드에서 빠짐 | 마이페이지 > 건강 프로필 | USER-010, OCR-007, GUIDE-002 |

**예외 흐름**

1. 처방전에서 단계 순서를 알 수 없으면 시스템이 임의로 정렬하지 않고, 회원이 순서를 정하게 해요. '순서가 확실하지 않으면 약사에게 확인해 주세요'를 보여주고, 진료 준비 질문 목록 '병원에 물어볼 것'에 추가해요. (MED-013, MED-015)
2. 퇴원 약물 섹션을 못 찾으면 약은 등록하지 않고 처방전이나 약봉투로 등록하라고 안내해요. 읽은 진단명은 회원이 고른 것만 저장하고, 주의사항은 저장하지 않아요. (OCR-006)
3. '처방전'을 고르고 퇴원요약지를 올리면 '처방전이 아닙니다' 경고를 띄우고 문서 종류를 다시 고르게 해요. (OCR-001)
4. 이미 사흘 먹은 뒤 등록하면 시작일과 현재 단계를 고를 수 있고, 등록 후에는 아직 시작하지 않은 단계만 고칠 수 있어요. (MED-013)

**확인 포인트**

- [ ] 입원 중 맞은 약이 처방으로 등록되지 않음
- [ ] 날짜별 용량이 가이드·캘린더·오늘의 복약에서 모두 같음
- [ ] 감량 일정으로 묶인 약에 같은 성분 중복 경고가 뜨지 않음
- [ ] 퇴원요약지로 등록하면 수령 전 안내가 뜨지 않음
- [ ] 진단명과 주의사항이 문서 원문 그대로 표시됨

※ 데모데이 차별점 시연은 자가주사(시나리오 1-B)로 정했고, 이 시나리오는 2차 기능 흐름입니다.

## 시나리오 3. 내 생활에 맞춘 복용 시간표 (차별점)

**가상 회원 C** · 34세 직장인. 평일에는 07:00에 일어나 아침을 거르고, 12:30 점심, 19:30 저녁, 00:30에 자요. 주말에는 09:00에 일어나 세 끼를 다 먹어요. 위염으로 위장약(1일 3회 식후 30분, 7일)과 수면에 도움을 주는 약(1일 1회 취침 전, 7일)을 처방받았어요.

| 단계 | 회원 행동 | 시스템 동작 | 화면 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 건강 프로필에서 평일·주말 일과를 따로 입력하고, 평일 아침은 '먹지 않음', 취침은 00:30으로 입력 | 자정을 넘긴 취침을 같은 하루의 취침으로 저장. 하루는 기상부터 다음 기상 전까지 | 마이페이지 > 건강 프로필 | USER-013 |

**예외 흐름**

1. 일과를 입력하지 않았다면 기본값(기상 07:00, 식사 08:00 / 12:30 / 18:30, 취침 23:00)으로 계산하고 '기본값 사용 중'을 표시해요. (USER-013)
2. 회원이 약사에게 물어보지 않고 위장약 시각을 직접 바꾸면, 식후 약을 식사 전으로 옮기는 경우 경고를 띄우고, 저장은 허용하되 진료 준비 질문에 남겨요. (MED-010)
3. 점심이 아침보다 이르게 입력하면 저장하지 않고 다시 입력하라고 안내해요. (USER-013)

**확인 포인트**

- [ ] 일과로 처방 조건을 지킬 수 없을 때 시스템이 임의로 시간을 정하지 않음
- [ ] 첫날 등록 전에 지나간 회차가 '미복용'으로 기록되지 않음
- [ ] 자정 넘어 먹은 취침 전 약이 전날 기록으로 남음
- [ ] 일과를 바꿔도 오늘 이미 체크한 기록은 바뀌지 않음
- [ ] 해결된 질문이 지워지지 않고 '해결됨'으로 남음
- [ ] 같은 일과·처방이면 시간표가 항상 같게 계산됨 (NFR-015)
