## 3. 논의 내용

### 안건 1. 1차 축소안

- 일정에 맞춰 1차 범위를 줄인 축소안을 확정했습니다.
- 약 검색(MED-001)은 직접 등록에 꼭 필요해서 1차로 올렸습니다.

### 안건 2. API 공통 규칙과 담당

- 민정님이 공통 규칙을 확정했습니다.
  - 남의 데이터에 접근하면 403 대신 404
  - 경로 변수 이름은 `{대상}_id`
  - access token 30분, refresh token 14일
  - 건강 프로필이 없으면 `PROFILE_REQUIRED`
- 처방 저장은 공통 함수 `create_prescription()` 하나로 처리하고, 민정님이 맡습니다.
- 약 검색 `GET /drugs?q=`는 채민님 담당으로 합쳤습니다.
- API 명세서 각 장의 담당자를 나눴습니다.

### 안건 3. 화면 흐름

- 처방을 저장하면 홈으로 이동합니다.
- 로그아웃은 헤더에만 둡니다.
- 식사 시간 선택은 홈에서 합니다. (설아, 채민)

### 안건 4. ERD와 알림

- ERD를 34개 테이블로 정리했습니다 (1차 20개).
- 카카오톡 알림은 2차, 보호자 알림은 3차로 미룹니다.
- 가이드 생성 실패 상태(failed)를 추가했습니다.

### 안건 5. 테스트 처방전과 숙제 분담

- 테스트 처방전 10건은 재경님이 준비합니다.
- 멘토링 숙제를 나눴습니다.

  - RAG 비교 테스트: AI 파트 (채민, 유정)
