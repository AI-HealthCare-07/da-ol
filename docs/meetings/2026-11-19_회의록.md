### 안건 2. 서비스 범위

- DB는 PostgreSQL로 정했습니다.
- 로그인은 카카오만 씁니다. 이메일·네이버 로그인과 비밀번호 재설정은 없습니다.
- 탈퇴하면 30일 동안 재가입할 수 없고, 그 뒤에는 새로 가입할 수 있습니다.
- 약 범위는 먹는 약만입니다. 주사, 안약, 연고 등은 제외합니다.
- 퇴원요약지, 감량 일정, 냉장 보관 안내는 제외합니다.
- 먹는 약 투여 주기(주 1회 약 등, MED-025)는 2차로 남깁니다.
- 대표 타겟: 고혈압·당뇨·이상지질혈증으로 여러 약을 오래 먹는 중장년·고령 환자
- 차별점: 원형 약통 + 꽃 피우기·화단 (1차는 원형 약통과 꽃 피우기)

### 안건 3. 요구사항 정의서 v10

- 총 77개 (1차 39 / 2차 27 / 3차 11)

- 빠지거나 합쳐진 요구사항은 '범위 제외 (11-19)' 시트에 원문과 사유를 남겼습니다. 빠진 ID는 다시 쓰지 않습니다.
- 함께 수정한 문서: ERD (37개 테이블, 1차 25 / 2차 7 / 3차 5), API 명세서 파트 B (1차 15개), 사용자 시나리오, 홈 화면 콘셉트

### 안건 4. 1주차 멘토링

- **RAG가 꼭 필요한가**: 복약 가이드는 처방 약이 공공데이터 ID와 연결돼 있어서 DB에서 바로 꺼내 쓸 수 있습니다. 생활습관 가이드와 챗봇에는 검색이 필요할 수 있습니다. 숙제 테스트 결과를 보고 정합니다.
- **reranker 대신 제브(Jev)**: 멘토님이 BGE reranker보다 판단 전용 모델이 낫다고 하셨습니다. 비용, 한국어 성능, 개인정보 마스킹을 확인해야 합니다.
- 숙제
  1. Claude Code 써보기: Skills, MCP 개념 공부
  2. 데이터 정리 + RAG 테스트: RAG / LLM Wiki / AI Agent 세 방식의 토큰 사용량 비교
  3. AWS 권한 확인: 터미널에서 실행하는 방법 확인
