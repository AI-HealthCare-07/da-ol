  - Elastic IP + Let's Encrypt 인증서 (certbot)
  - Vercel에서 `/api`를 백엔드로 넘겨서 쿠키를 같은 사이트로 씁니다.
  - 안 되면 api.daol.site로 직접 호출하고 CORS를 엽니다 (플랜 B).

### 안건 3. API 명세서 리뷰 반영

- 약 복용량 수정 API(`PATCH /prescription-items`)는 1차에서 빼고, 기획문서 전부에서 지웠습니다.
- 5장 규칙을 정했습니다.
  - 홈 주간 기록은 항상 오늘 포함 7일
  - '복용 중'은 종료일이 오늘 이후인 처방 (시작일과 상관없음)
  - 처방 목록 탭은 처방 단위
  - 확인이 필요한 복용 조건은 `PATCH /dose-conditions`로 조건마다 고침
- 공통 함수: `get_daily_intakes()` (오늘 복약, /intakes와 /home이 같이 씀), `validate_drug_input()` (처방 입력 검사)
- 스캔 삭제(`DELETE /scans/{scan_id}`)는 기록을 남기고 상태만 expired로 바꿔서, 하루 OCR 20회 제한에 계속 포함합니다.
- 가이드 실패 문구: "가이드 생성이 지연되고 있어요. 잠시 후 다시 시도해 주세요"
- 요구사항 정의서와 교차 검증해서 다른 부분을 정의서·ERD·와이어프레임에 반영했습니다. 지원 브라우저는 크롬만으로 정했습니다.

### 안건 4. drugs 테이블

- 공공데이터 출처를 구분하려고 컬럼 3개를 추가했습니다.
  - `data_source` (easy_drug / permit)
  - `source_updated_at` (원본 수정일)
  - `is_otc` (일반의약품 여부)
- 화면의 "OO 기준" 날짜는 `data_fetched_at`을 씁니다.
- 공공데이터 키는 환경변수 `DATA_GO_KR_SERVICE_KEY`로 관리합니다.
