# 화면 설계 (와이어프레임) - 파트 A

> - 담당: 김설아
> - 범위: 공통 레이아웃 + 홈, 로그인/회원가입, 내 약 목록, 약 상세 정보, 건강 프로필, 내 정보/회원탈퇴
> - 기준: 요구사항 정의서 최종본(79개), 사용자 시나리오(user-scenarios.md)
> - 화면 번호: 사용자 시나리오의 '와이어프레임용 화면 목록'과 같음 (A-1 ~ A-6)
> - 표시: `(2차)`·`(3차)`가 없으면 1차 구현 범위
> - Figma 링크: (링크 추가 예정)

## 공통 레이아웃 (파트 B 화면도 같이 사용)
- **시나리오:** 전체
- **화면 폭:** 360px 모바일 기준으로 그리고, 1920px 데스크톱까지 깨지지 않게 반응형 (REQ-NFR-008)
- **상단 헤더:**
  - 하위 화면: 뒤로가기 버튼 + 페이지 제목
  - 메인 화면(홈·내 약·마이페이지): 서비스 로고 + 오른쪽 메뉴(`로그아웃`) (REQ-USER-006)
  - 오른쪽 종 아이콘 자리는 비워 둠 (알림 센터, 3차)
- **하단 탭 바 (로그인 후 메인 화면):** `홈` / `내 약` / `[+ 처방 등록]`(가운데 강조 버튼) / `가이드` / `마이페이지`
  - 탭 구성은 파트 B와 함께 확정
- **챗봇 플로팅 버튼:** 우측 하단, 하단 탭 바 바로 위 (REQ-CHAT-001)
  - 로그인·회원가입, 처방 촬영 화면에서는 숨김
  - 360px 화면에서 하단 버튼과 겹치지 않게 배치
- **글자·버튼 크기:** 본문 16px 이상, '글자 크게 보기'를 켜면 본문 20px, 주요 버튼 최소 44×44px (REQ-NFR-009)
- **공통 컴포넌트 (두 파트가 같은 모양으로 사용):**
  - `확인이 필요해요` 배지 + 노란색 배경 (확인 필요 항목)
  - `복용 시간 확인 필요` 배지
  - `기본값 사용 중` 배너
  - `냉장 보관` 배지 (2차)
  - 빈 상태 화면 (아이콘 + 안내 문구 + 행동 버튼)
  - 확인 팝업 (제목 + 설명 + `[취소]` / `[확인]`)

## A-1. 로그인 / 회원가입
- **시나리오:** 1

### A-1-1. 로그인 (REQ-USER-004)
- **상단 영역:** 서비스 로고 + 한 줄 소개
- **입력 영역:** 이메일, 비밀번호 입력창
- **액션 버튼:** `[로그인]`
- **보조 링크:** `[회원가입]` / `[비밀번호 찾기]`(2차)
- **소셜 로그인 영역 (2차, 자리만):** `[카카오로 시작하기]` / `[네이버로 시작하기]`
- **예외 안내:**
  - 입력창 아래 `이메일 또는 비밀번호가 올바르지 않습니다` (어느 쪽이 틀렸는지 구분하지 않음)
  - 5회 연속 실패 시 `로그인이 10분간 제한됩니다. 남은 시간: ○분`

### A-1-2. 회원가입 (REQ-USER-001)
- **입력 폼:**
  - `이메일` (필수, `[중복 확인]` 버튼)
  - `비밀번호` (필수, 8~20자, 영문·숫자·특수문자 각 1자 이상, 조건 안내 문구)
  - `비밀번호 확인` (필수, 불일치 시 안내)
  - `닉네임` (필수, 2~10자)
  - `이름`, `생년월일`(YYYY-MM-DD), `성별` (필수)
- **약관 동의 영역:**
  - `[ ] 전체 동의`
  - `[ ] 서비스 이용약관 (필수)` / `[ ] 개인정보 수집·이용 (필수)` / `[ ] 민감정보(건강정보) 수집·이용 (필수)`, 각 항목 `[보기]`
- **하단 고정 버튼:** `[가입하기]` (필수 항목·동의 누락 시 비활성화)
- **예외 안내:** `이미 가입된 이메일입니다`
- **가입 후:** 홈으로 이동 (등록한 약이 없으므로 홈 빈 상태 화면)

---

## A-2. 홈 (오늘의 복약) (REQ-MED-005)
- **시나리오:** 1, 1-B, 2, 3
- **상단 요약:** 오늘 날짜 + 날짜 이동 화살표(`< 어제` / `오늘 >`, 최근 3일까지) + 오늘 복약 현황(예: `3개 중 2개 완료`)
- **기본값 배너:** 생활 일과를 입력하지 않은 회원에게 `기본값 사용 중 · 내 일과 입력하기` 표시 → 건강 프로필의 생활 일과로 이동 (REQ-USER-013)
- **복용 시각별 카드 목록:**
  - 카드: 시각(예: `07:30`) + 약 이름(상품명) + 1회 용량 + 체크 버튼(다시 누르면 취소)
  - 30분 이내 약은 한 카드로 묶어 표시. 식전 약과 식후 약은 묶지 않음 (REQ-MED-009)
  - 주사약은 투여일에만 표시하고 `주사` 라벨을 붙임 (REQ-MED-012)
  - `복용 시간 확인 필요` 배지가 붙은 약은 시각 대신 안내 문구 표시 (REQ-MED-009)
  - 용량이 바뀌는 날 `오늘부터 ○정입니다` (2차, REQ-MED-013)
  - 시각 옆 연필 아이콘으로 시각 수정 (2차, REQ-MED-010)
- **필요할 때 복용 영역:** 필요시 복용 약은 시간표와 따로 목록으로 표시 (REQ-MED-008)
- **빈 상태:** `처방전을 찍어 약을 등록해 보세요` + `[처방 등록하기]` → 파트 B-1

## A-3. 내 약 목록 (REQ-MED-002)
- **시나리오:** 1, 1-B
- **탭:** `복용 중` / `복용 종료`
- **처방 묶음 헤더:** 병원명 · 처방일 + `[가이드 보기]` → 파트 B-5 / `⋮` 메뉴(수정·삭제, 2차, REQ-MED-004)
- **약 카드:**
  - 상품명(성분명) (예: `다이아벡스(메트포르민)`)
  - 복용법 (예: `1일 3회 식후 30분`, 주사약은 `주 1회 · 토요일`)
  - 남은 일수, 주사약은 다음 투여일 (예: `다음 투여 11/21(토)`)
  - 병용 주의 표시 (REQ-MED-007)
  - `냉장 보관` 배지 (2차, REQ-MED-014)
- **카드 클릭:** A-4 약 상세 정보로 이동
- **빈 상태:** `등록한 약이 없어요` + `[처방 등록하기]`

---

## A-4. 약 상세 정보 (REQ-MED-003)
- **시나리오:** 1
- **상단 영역:** 약 이미지(공공데이터에 있을 때) + 상품명(성분명) + 제조사
- **내 복용 정보 카드:** 복용 조건(회차별), 계산된 복용 시각, 남은 일수 / `[복용 시각 수정]` (2차, REQ-MED-010)
- **약 정보 섹션 (접기/펼치기):** 효능, 용법·용량, 주의사항, 주요 부작용, 보관법
- **하단 영역:** 데이터 출처 + 기준일 (예: `출처: 식약처 공공데이터 · 2026-11-01 기준`)
- **예외:** 공공데이터에 없는 약은 `이 약은 안내 정보가 없습니다` 표시, 복용 정보 카드만 보여줌 (REQ-OCR-005)

---

## A-5. 건강 프로필 (마이페이지 > 건강 프로필 탭) (REQ-USER-010, REQ-USER-013)
- **시나리오:** 1, 3
- **기본 정보:** 키(cm), 몸무게(kg)
- **기저질환:** 다중 선택 칩 (`고혈압` / `당뇨` / `이상지질혈증` / `심장질환` / `신장질환` / `간질환` / `없음` / `기타 직접입력`)
- **기타 항목:** 약물·식품 알레르기(직접입력), 임신·수유 여부(여성만 표시), 흡연 여부, 음주 빈도(주 n회), 운동 빈도(주 n회)
- **생활 일과 섹션:**
  - `평일` / `주말` 토글 (교대 근무자용 `요일별 입력`은 선택 기능)
  - 기상 / 아침 / 점심 / 저녁 / 취침 시간 선택, 끼니마다 `먹지 않음` 체크
  - 예외: 식사 시간 순서가 맞지 않으면 저장하지 않고 안내
  - 이 폼은 B-3에서 첫 처방을 저장한 뒤 뜨는 '일과 입력 팝업'과 같은 컴포넌트로 만들고, 팝업에는 `[나중에 하기]` 버튼을 추가
- **진료 기록 진단명 (2차, REQ-OCR-007):** `현재 앓고 있는 병` / `지난 병` 목록, 진단명 옆 출처, `[지난 병으로 옮기기]`
- **하단 고정 버튼:** `[저장]`
- **저장 후 (2차, REQ-MED-011):** 일과가 바뀌면 바뀌는 복용 시각의 변경 전후 팝업 → `[적용]`

---

## A-6. 내 정보 / 회원탈퇴 (마이페이지 > 내 정보 탭)
- **시나리오:** 1
- **마이페이지 탭:** `내 정보` / `건강 프로필` / `알림 설정`(3차) / `화면 설정`
- **내 정보 (REQ-USER-008):** 프로필 이미지, 이메일, 닉네임, 이름, 생년월일, 성별, 가입 경로
- **정보 수정 (2차, REQ-USER-009):** `[수정]` → 프로필 이미지, 닉네임, 비밀번호(현재 비밀번호 확인 후)만 수정 가능
- **화면 설정 탭:** `글자 크게 보기` 토글 (REQ-NFR-009)
- **회원탈퇴 (2차, REQ-USER-011):**
  - 내 정보 탭 하단 `회원탈퇴` 텍스트 버튼
  - 확인 팝업: `탈퇴하면 30일 후 개인정보, 건강 프로필, 처방·복약 기록, 챗봇 대화가 모두 삭제돼요` + 비밀번호 재입력(이메일 가입 회원) + `[취소]` / `[탈퇴하기]`

## 파트 A ↔ 파트 B 연결
- 하단 탭 `[+ 처방 등록]`, 홈·내 약 빈 상태 버튼 → B-1 처방 등록
- B-3 `[확인 및 저장]` → 첫 처방이면 일과 입력 팝업(A-5 컴포넌트) → B-5 가이드(진행 상태 표시) → 홈(A-2)에 시간표 반영
- 홈의 `기본값 사용 중` 배너 → A-5 생활 일과
- A-3 `[가이드 보기]`, 하단 탭 `가이드` → B-5
- B-5 건강 프로필 미등록 팝업 `[프로필 입력하기]` → A-5
- 챗봇 플로팅 버튼 → B-6

## 이번 범위에서 안 그리는 화면 (2차·3차)
- 진료 준비 질문 목록, 복약 기록 캘린더 (2차)
- 알림 설정, 알림 센터 (3차)
